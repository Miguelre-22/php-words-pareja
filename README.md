# PHP Words

Aplicación web que muestra las palabras reservadas de PHP con su categoría y una breve descripción.

## Cómo ejecutar

Abrir index.html en el navegador (doble clic).
Requiere un navegador moderno.

## Funcionalidades
- Lista de palabras reservadas de PHP con su categoría y descripción.
- Buscador por texto en tiempo real.
- Filtro por categoría.
- Contador de palabras mostradas.

## Estructura del proyecto
- `index.html`: página principal.
- `css/estilos.css`: estilos.
- `js/config.js`: título, subtítulo y versión.
- `js/palabras.js`: lista de palabras.
- `js/app.js`: filtrado y pintado de la lista.
- `js/buscador.js` y `js/categorias.js`: controles de búsqueda y filtro.
